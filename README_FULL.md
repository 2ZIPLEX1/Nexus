## 🎯 Что это такое?

**Steam Trading Bot** - это автоматизированный бот для торговли предметами CS2 (CS:GO) на Steam Market и CSGO.TM.

### Основная идея:
1. **Сканирование** - бот ищет выгодные предметы на CSGO.TM
2. **Покупка** - автоматически создаёт buy orders на Steam Market
3. **Продажа** - после холда (7 дней) предметы можно продать на CSGO.TM с профитом

### Зачем это нужно?
- 💰 **Пассивный доход** - бот работает 24/7
- 📊 **Аналитика** - расчёт профита с учётом комиссий
- 🤖 **Автоматизация** - минимум ручной работы
- 📈 **Статистика** - отслеживание ROI и профита

## 🚀 Установка с нуля

### Требования

**Системные требования:**
- Windows 10/11 или Linux
- Python 3.10 или выше
- 4 GB RAM (рекомендуется 8 GB)
- 500 MB свободного места на диске

**Steam аккаунт:**
- ✅ Активный Steam аккаунт
- ✅ Steam Guard Mobile Authenticator настроен
- ✅ Средства на балансе Steam
- ✅ Доступ к `shared_secret` и `identity_secret` (для авто-подтверждений)

### Шаг 5: Получение Steam секретов

Для автоматического подтверждения покупок нужны `shared_secret` и `identity_secret`.

#### Способ 1: Steam Desktop Authenticator (Windows)

1. Скачайте [Steam Desktop Authenticator](https://github.com/Jessecar96/SteamDesktopAuthenticator)
2. Настройте Mobile Authenticator через программу
3. Откройте файл `maFiles/<ваш_steamid>.maFile`
4. Найдите строки:
   ```json
   {
     "shared_secret": "ваш_shared_secret_здесь",
     "identity_secret": "ваш_identity_secret_здесь"
   }
   ```
5. Скопируйте эти значения

#### Способ 2: Мобильное приложение (Android)

1. Установите приложение для извлечения секретов (например, Root требуется)
2. Или используйте эмулятор Android с root правами
3. Извлеките файл `/data/data/com.valvesoftware.android.steam.community/files/Steamguard-<steamid>`
4. Откройте JSON и найдите `shared_secret` и `identity_secret`

**⚠️ ВАЖНО:**
- Никому не показывайте эти секреты!
- С ними можно получить полный доступ к вашему аккаунту
- Храните в безопасном месте

### Шаг 2: Заполнение .env файла

Откройте `.env` и заполните следующие поля:

```env
# ===== ОСНОВНЫЕ НАСТРОЙКИ =====

# Steam credentials
STEAM_USERNAME=ваш_логин_steam
STEAM_PASSWORD=ваш_пароль_steam

# Steam Guard секреты (получили на предыдущем шаге)
STEAM_SHARED_SECRET=ваш_shared_secret
STEAM_IDENTITY_SECRET=ваш_identity_secret

# API ключ Steam (получите на https://steamcommunity.com/dev/apikey)
STEAM_API_KEY=ваш_api_key

# ===== НАСТРОЙКИ СКАНЕРА =====

# Минимальный профит для отображения (в процентах)
MIN_PROFIT_PCT=15.0

# Максимальная цена предмета (в рублях)
MAX_ITEM_PRICE=5000.0

# Интервал сканирования (в минутах)
SCAN_INTERVAL=30

# ===== НАСТРОЙКИ AUTO BUYER =====

# Максимальное количество предметов для покупки за раз
MAX_ITEMS_TO_BUY=5

# Общий бюджет для покупок (в рублях)
TOTAL_BUDGET=5000.0

# Автоматическое подтверждение покупок
AUTO_CONFIRM=true

# ===== НАСТРОЙКИ ПРОКСИ =====

# Использовать прокси (true/false)
USE_PROXY=false

# Прокси в формате: socks5://user:pass@ip:port
# Можно указать несколько через запятую
PROXY_LIST=

# ===== НАСТРОЙКИ ВАЛЮТЫ =====

# Валюта Steam аккаунта (RUB, USD, EUR, KZT)
CURRENCY=RUB
```

---

### Шаг 3: Получение Steam API Key

1. Зайдите на https://steamcommunity.com/dev/apikey
2. Войдите в свой Steam аккаунт
3. Заполните форму:
   - **Domain Name:** `localhost` (или любой другой)
   - Согласитесь с условиями
4. Нажмите "Register"
5. Скопируйте ключ (формат: `XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX`)
6. Вставьте в `.env` файл в поле `STEAM_API_KEY`

### Шаг 5: Настройка прокси (опционально)

Если у вас несколько аккаунтов, рекомендуется использовать прокси для обхода лимитов Steam.

#### Создайте файл `proxies.txt`:

```txt
socks5://user1:pass1@ip1:port1
socks5://user2:pass2@ip2:port2
socks5://user3:pass3@ip3:port3
```

**Формат:**
- `socks5://` - тип прокси (SOCKS5)
- `user:pass` - логин и пароль прокси
- `ip:port` - IP адрес и порт

**Где купить прокси:**
- [proxy6.net](https://proxy6.net/) - от 60₽/месяц
- [proxyline.net](https://proxyline.net/) - от 50₽/месяц
- [youproxy.ru](https://youproxy.ru/) - от 40₽/месяц

## 📖 Подробное руководство по функциям

### 1. Управление аккаунтами (вкладка "👤 Аккаунты")

#### Авторизация:

1. Откройте вкладку "👤 Аккаунты"
2. Выберите аккаунт из списка
3. Нажмите кнопку "🔑 Логин"
4. Подождите 5-10 секунд
5. Статус изменится на "✅ Online"

**Возможные проблемы:**
- `❌ Invalid credentials` - неправильный логин/пароль
- `❌ 2FA code required` - проверьте `shared_secret`
- `❌ Rate limit` - подождите 5 минут и попробуйте снова

#### Проверка баланса:

1. После авторизации нажмите "💰 Баланс"
2. Отобразится текущий баланс кошелька
3. Формат: `1234.56 ₽` (или USD/EUR/KZT)

#### Определение валюты:

1. Нажмите "🔍 Валюта"
2. Бот автоматически определит валюту аккаунта
3. Сохранится в конфигурации

#### Включение/выключение аккаунтов:

- Переключатель справа от аккаунта
- **ON** (зелёный) - аккаунт активен
- **OFF** (серый) - аккаунт отключён

### 2. Сканирование предметов (вкладка "🔍 TM Parser")

#### Запуск сканирования:

1. Откройте вкладку "🔍 TM Parser"
2. Настройте фильтры:
   - **Min Profit %** - минимальный профит (например, 15%)
   - **Max Price** - максимальная цена (например, 5000₽)
3. Нажмите кнопку "🔍 Сканировать"
4. Подождите 1-3 минуты

**Процесс сканирования:**
```
🔍 Сканирование CSGO.TM...
📊 Найдено 150 предметов на CSGO.TM
🔄 Получение цен Steam Market... (это может занять время)
✅ Сканирование завершено! Найдено 23 выгодных предмета
```

#### Просмотр результатов:

После сканирования отобразится таблица:

| Предмет | TM Buy | TM Sell | Steam Buy | Profit % | Profit ₽ |
|---------|--------|---------|-----------|----------|----------|

**Столбцы:**

### 3. Автоматическая покупка (Auto Buyer)

#### Запуск Auto Buy:

1. После сканирования нажмите "🛒 Auto Buy"
2. Откроется диалог настроек:

**Процесс покупки:**
```

💰 Покупка 1/5: AK-47 | Redline (FT) за 1400.00 ₽

✅ Buy order создан: #12345679

✅ Покупка завершена! Куплено: 5, Потрачено: 4500.00 ₽
🔄 Автоматическое подтверждение...

```

#### Blacklist/Whitelist (в коде):

Для фильтрации предметов отредактируйте код или дождитесь GUI:

```python
from src.auto_buyer import AutoBuyer

buyer = AutoBuyer(
    steam_client=steam_client,
    db=trades_db,
    account_name="MyAccount",
    blacklist=["P90 | Elite Build", "MP9 | Hot Rod"],  # Не покупать эти
    whitelist=[]  # Если указать - покупать только эти
)
```

#### Приоритизация:

```python
stats = buyer.auto_buy_from_list(
    items=items,
    prioritize_by='profit'  # 'profit' | 'price' | 'roi'
)
```

**Режимы:**
- `profit` - покупать самые выгодные сначала (по % профита)
- `price` - покупать самые дешёвые сначала
- `roi` - оптимизировать ROI (профит% / цена)

## 🔧 Решение проблем

### Проблема: GUI не запускается

**Ошибка:**
```
ModuleNotFoundError: No module named 'customtkinter'
```

**Решение:**
```bash
# Активируйте виртуальное окружение
venv\Scripts\activate  # Windows
source venv/bin/activate  # Linux

# Переустановите зависимости
pip install -r requirements.txt
```

---

### Проблема: Не могу залогиниться

**Ошибка:**
```
❌ Invalid credentials
```

**Решение:**
1. Проверьте логин и пароль в `accounts.json`
2. Проверьте `shared_secret` - должен быть правильным
3. Убедитесь что Steam Guard включён
4. Попробуйте залогиниться в Steam через браузер - возможно нужна капча

---

### Проблема: Ошибка rate limit

**Ошибка:**
```
❌ Rate limit exceeded
```

**Решение:**
1. Подождите 5-10 минут
2. Используйте прокси для множественных аккаунтов
3. Уменьшите частоту сканирования
4. Не делайте больше 20 запросов в минуту

---

### Проблема: Цены не отображаются (0.00₽)

**Решение:**
Обновитесь до версии 2.1.2:
```bash
git pull origin main
pip install -r requirements.txt --upgrade
```

---

### Проблема: Подтверждения не работают

**Проверьте:**
1. `identity_secret` правильно указан
2. `shared_secret` правильно указан
3. Steam Guard включён
4. Попробуйте подтвердить вручную через мобильное приложение

**Тест:**
```bash
python -c "from src.confirmations import ConfirmationHandler; from src.steam_client import SteamClient; print('OK')"
```

---

### Проблема: База данных повреждена

**Ошибка:**
```
sqlite3.DatabaseError: database disk image is malformed
```

**Решение:**
```bash
# Создайте бэкап (если есть важные данные)
copy data\my_trades.db data\my_trades_backup.db

# Удалите повреждённую БД
del data\my_trades.db

# Перезапустите бота - БД создастся заново
python gui.py
```

- ✅ Не использует читы или эксплойты
